달동네 전용 서버 (Windows)

화면 없이 도는 게임 서버입니다. 서버로 쓸 컴퓨터에서 켜 두면 사람들이 들어와 같이 놀 수 있습니다.
게임을 하는 사람의 게임과 이 서버는 같은 버전이어야 합니다. (버전이 다르면 "버전이 달라 들어갈 수 없습니다"가 나옵니다)

필요한 것
- Windows 10 또는 11 (64비트)
- 50명이 모두 움직일 때 이 PC에서 잰 값: CPU 한 코어의 60~70%, 메모리 약 300MB, 업로드 약 6Mbps
  (집 인터넷이면 업로드 속도가 10Mbps 이상인지 확인하세요)

----------------------------------------------------------------
1. 켜기
----------------------------------------------------------------
1. 압축을 아무 폴더에 풉니다.
2. server\settings.json 을 메모장으로 열어 서버 이름 등을 고칩니다. (아래 "3. 설정 파일")
3. StartServer.bat 을 더블클릭합니다.
   - 방화벽 창이 뜨면 "허용"을 누릅니다.
   - 검은 창에 "listening on ... :7777" 줄이 보이면 켜진 것입니다.
   - 처음 켜면 새 월드를 만들고, 그 월드 이름(id)을 settings.json 의 "world" 칸에 적어 둡니다.
     다음에 켜면 같은 월드로 이어집니다.
4. 이 검은 창이 서버 콘솔입니다. 창을 닫지 말고 켜 두세요.

----------------------------------------------------------------
2. 끄기 (꼭 이렇게 끄세요)
----------------------------------------------------------------
- 콘솔 창에 stop 을 치고 Enter 를 누릅니다. 월드를 저장하고 꺼집니다.
- Ctrl+C 를 눌러도 저장하고 꺼집니다.
- 창의 X 를 누르면 Windows가 몇 초만 기다려 줘서 저장이 안 될 수도 있습니다. stop 을 쓰세요.
- 월드는 켜져 있는 동안 1분마다 자동으로 저장됩니다.

----------------------------------------------------------------
3. 설정 파일 (server\settings.json)
----------------------------------------------------------------
메모장으로 고치고 저장하면 됩니다. 따옴표와 쉼표를 지우지 않게 조심하세요.

  "name": "달동네 전용 서버"   서버 이름. 서버 목록과 접속 화면에 보입니다. (30자까지)
  "maxPlayers": 20            최대 인원. 2~50
  "isPublic": true            true = 공개 서버 목록에 나옴 / false = 서버 코드나 주소를 아는 사람만
  "password": ""              비밀번호. 빈 칸이면 비밀번호 없음
  "port": 7777                포트 번호
  "world": ""                 월드 id. 빈 칸이면 새 월드를 만들고 여기에 적습니다.
                              다른 월드를 쓰려면 server\worlds 안의 폴더 이름을 적습니다.
  "admins": []                관리자 계정 목록. 예: ["0002abcd...", "0002ef01..."]
                              보통은 직접 적지 않고 콘솔에서 admin <캐릭터 이름> 으로 넣습니다.
  "bans": []                  차단한 계정 목록. 콘솔이나 채팅의 ban 명령이 여기에 적습니다.
  "nightSkip": "0-6"          밤 건너뛰기. "0-6" = 밤 0시~6시를 건너뜀. "0-0" = 건너뛰지 않음.
                              빈 칸("")이면 월드에 저장된 값을 그대로 씁니다.
  "trafficCars": 8            NPC 차 수. 0~10. (10대보다 많으면 차 흐름이 반복되지 않아 차가 튀어 보여서 막아 두었습니다)

서버가 켜진 채로 고쳐도 되는 것 (저장하면 1초 안에 바로 적용):
  admins, bans, nightSkip, trafficCars
서버를 껐다 켜야 적용되는 것:
  name, maxPlayers, isPublic, password, port, world
  (켜진 채로 고치면 콘솔에 "needs a restart" 라고 나옵니다)

----------------------------------------------------------------
4. 관리자 명령
----------------------------------------------------------------
서버 콘솔에서는 그냥 칩니다.        예: kick 홍길동
게임 채팅(Enter)에서는 / 를 붙입니다. 예: /kick 홍길동
채팅 명령은 관리자만 쓸 수 있습니다. 관리자가 아니면 "관리자만 쓸 수 있는 명령입니다."가 나옵니다.

  help                       명령 목록
  players                    접속한 사람의 이름과 계정 id
  kick <이름>                서버에서 내보냄 (다시 들어올 수는 있음)
  ban <이름 또는 계정>       차단. 접속 중이면 내보내고, 다시 들어오지 못함
  unban <이름 또는 계정>     차단 풀기
  admin <이름 또는 계정>     관리자로 정함 (콘솔에서만)
  unadmin <이름 또는 계정>   관리자에서 뺌 (콘솔에서만)
  say <글>                   모든 사람의 채팅에 공지
  save                       지금 월드 저장
  time <시>[:<분>]           게임 시각을 다음 그 시각으로 옮김. 예: time 9, time 21:30
  stop                       월드를 저장하고 서버를 끔

- <이름> 은 이 월드의 캐릭터 이름입니다. 대소문자는 구분하지 않습니다.
- 관리자는 다른 관리자를 내보내거나 차단할 수 없습니다. 관리자 지정·해제는 콘솔에서만 됩니다.

처음 관리자 정하기
1. 내 게임으로 서버에 들어가 캐릭터를 만듭니다. (캐릭터 이름 예: 홍길동)
2. 서버 콘솔에 admin 홍길동 을 칩니다.
3. 이제 게임 채팅에서 /kick, /say 같은 명령을 쓸 수 있습니다.

----------------------------------------------------------------
5. 사람들이 들어오는 방법
----------------------------------------------------------------
- 공개 서버("isPublic": true)이고 인터넷이 되면, 게임의 참가하기 > 공개 서버 목록에 나옵니다.
- 서버 코드(6자)로도 들어올 수 있습니다. 코드는 콘솔의 "session XXXXXX" 줄과 server\running.json 에 있습니다.
- 주소로 직접 들어오기: 참가하기 > 직접 주소 입력
    같은 컴퓨터: 127.0.0.1:7777
    같은 공유기(집 안): 서버 컴퓨터의 내부 IP (예: 192.168.0.5:7777)
    인터넷의 다른 집: 공유기에서 TCP 7777 포트를 서버 컴퓨터로 열어(포트 포워딩) 주고, 공인 IP:7777 로 들어옵니다.
- 서버를 켠 Windows 사용자 계정과 같은 계정으로 같은 컴퓨터에서 게임을 하면, 목록이나 코드 대신 127.0.0.1:7777 로 들어오세요.

----------------------------------------------------------------
6. 파일
----------------------------------------------------------------
  server\settings.json   설정 파일
  server\worlds\<id>\    월드 (world.dat 와 바로 전 저장본 world.prev.dat)
  server\server.log      서버 기록 (문제가 생기면 이 파일을 보내 주세요)
  server\running.json    켜져 있는 동안만 있는 파일 (포트, 서버 코드)

백업: 서버를 끈 뒤 server\worlds 폴더를 통째로 복사해 두면 됩니다.

----------------------------------------------------------------
7. 잘 안 될 때
----------------------------------------------------------------
- 창이 바로 꺼지거나 "cannot open world ... or listen on port" 가 나옴:
  다른 프로그램(다른 서버 포함)이 같은 포트를 쓰고 있습니다. "port" 를 바꾸거나 그 프로그램을 끄세요.
- 공개 목록에 안 나옴: 인터넷 연결을 확인하세요. 켠 뒤 1분쯤 걸릴 수 있습니다. 주소로는 들어올 수 있습니다.
- 콘솔에 명령을 쳐도 반응이 없음: StartServer.bat 으로 켰는지 확인하세요. (exe 를 직접 실행하면 콘솔이 없습니다)
