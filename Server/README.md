# 서버 작업 공간

이 폴더는 서버 코드를 추가할 위치입니다. 아직 서버 코드와 프레임워크는 정해지지 않았습니다.

- 일반 API 서버는 Unity 그래픽 에셋을 빌드 의존성으로 사용하지 않도록 구성합니다.
- 클라이언트·서버가 공유할 건물 ID, 위치 데이터, 요청·응답 형식은 `Docs`에 API 계약으로 문서화합니다.
- 표시용 건물 이름과 저장·통신에 쓰는 ID는 구분하고, ID는 팀이 합의해서 고정합니다.
- Unity 전용 서버로 물리나 이동을 검증하는 방식을 선택하면 충돌·내비게이션 데이터 공유 범위를 별도로 정합니다.
- 실제 인증값은 환경 변수나 로컬 설정으로 관리하고, 필요한 설정 키는 `.env.example` 같은 예제 파일로 안내합니다.

백엔드 기술을 결정하면 이 폴더에 해당 프로젝트와 실행 안내를 추가하세요.
