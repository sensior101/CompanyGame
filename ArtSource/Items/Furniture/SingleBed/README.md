# 로우폴리 싱글침대

`SingleBed.blend`를 Blender로 열면 크림 색상의 원본과 촬영용 스튜디오가 있습니다.
`QA/`는 실제 Blender 렌더, `Exports/`는 침대만 내보낸 FBX/GLB입니다.

- 단위: 1 Blender unit = 1m, 바닥 중앙이 루트 원점.
- 기준 캐릭터: 현재 Player.prefab CharacterController 1.8m 및 MaleArticulated.fbx 실측.
- 매트리스: 폭 1m × 길이 2m × 두께 0.18m, 윗면 높이 0.525m.
- 전체: 폭 1.12m × 길이 2.12m × 헤드보드 높이 0.92m.
- 크림 / 세이지 / 블루 / 로즈 / 차콜. 모델 형상은 동일하며 재질만 변경됩니다.
- 프레임 / 매트리스 / 이불 / 접힌 이불 / 베개: 5개 재질 역할.
- 프레임, 다리, 매트리스, 이불, 베개는 편집 가능한 별도 메시로 구성됩니다.
- UV 포함. 외부 이미지 텍스처나 Blender 전용 프로시저럴 재질에 의존하지 않습니다.

## 색상 변경

각 메시의 MaterialRole 사용자 속성이 재질 역할을 나타냅니다.
재질 목록에서 `SingleBed_02_Sage_Frame`처럼 동일 역할의 다른 색상 재질로 교체할 수 있습니다.
모든 25개 재질은 원본에 보존됩니다. `Exports`에는 색상별 파일도 준비되어 있습니다.

## 제작 및 검증

Blender의 별도 백그라운드 프로세스에서 `build_single_bed.py` 실행 후 `verify_exports.py` 실행.
Cycles와 FBX 애드온이 필요합니다. 기존 LibraryKiosk의 미터 단위·독립 에셋 컬렉션·FBX 축 규칙을 따릅니다.
제작 스크립트는 이 침대의 형상과 팔레트를 재생성하기 위한 독립 아트 레시피입니다.
검증 스크립트는 내보낸 파일을 새 장면으로 다시 읽어 치수·삼각형·재질·UV·바닥 원점을 확인합니다.

## 작업 범위

- 기존 파일 수정 없음. 이 폴더의 모델 원본·내보내기·검증·미리보기만 신규 생성.
- 기존 FurnitureFunction.Sleep / FurniturePlacement.Floor 분류를 원본 속성에 기록.
- 런타임 클래스/메서드 추가나 변경 없음. 저장 데이터·이벤트·UI·기존 호출부 영향 없음.
- 데이터 흐름: Blender 형상 및 팔레트 → 동일 형상의 색상별 FBX/GLB → Blender 재수입 검증.
- 공통 기능 중복 구현 없음. 수면·소유권·배치 동작은 구현하지 않았습니다.
- Unity 임포트, URP 재질 연결, 콜라이더, 수면 애니메이션 및 Play-mode 검증은 미수행.
- 기존 가구 교체, 씬 배치, 커밋은 수행하지 않았습니다.
