# 가정용 가구 재질 컬렉션

완성된 가구 60종 × 4스타일 = 240개 버전입니다. `Catalog.html`을 열면 스타일과 가구 분류를 바꿔가며 실제 Blender 렌더와 모델 파일을 볼 수 있습니다.

| 폴더 | 재질 구성 |
| --- | --- |
| WhiteWood | 따뜻한 화이트, 내추럴 오크, 아이보리·베이지 패브릭 |
| Eclectic | 틸, 코랄, 머스터드, 딥퍼플 |
| MarbleGold | 대리석, 금속 골드, 아이보리·딥그린 패브릭 |
| ChicBlack | 블랙 오크, 차콜 패브릭, 건메탈 |

각 `스타일/가구ID/` 폴더에 `.blend`, `.fbx`, `.glb`, `Preview.png`, `Manifest.json`이 있습니다. `.blend`와 `.glb`에는 텍스처를 포함했고 FBX에도 이미지 텍스처를 임베드했습니다. `Textures/`에는 동일한 원본 PNG를 별도로 제공합니다. 모델의 단위는 미터입니다.

모델링은 원본 그대로입니다. 텍스처는 기존 UV를 사용하며 새 메시, 변형, 디스플레이스먼트 또는 조립부 변경이 없습니다. 쿠션·이불은 패브릭, 거울은 반사 금속, 화면·유리·고무는 해당 부위에 맞는 재질을 유지합니다. 같은 테마라도 가구의 구성 부위에 따라 사용되는 재질 조합은 다릅니다.

`SourcePreservation.json`은 기존 60종의 Blender 원본·기본 재질 출력물·기본 미리보기 총 240개 파일의 해시 보존 결과입니다. `RoundTripReport.json`은 네 스타일 480개 FBX/GLB 재수입 결과입니다. 저장된 240개 Blender 파일도 원본과 메시·UV·변환·스무딩·면의 재질 슬롯 번호를 비교합니다.

Blender 렌더와 FBX/GLB 재수입을 검증합니다. Unity 임포트, URP 재질 연결 및 게임 플레이는 수행하지 않았습니다. Unity에서 FBX의 반사·투명·금속 표면은 프로젝트 셰이더에 맞는 재질 연결이 필요할 수 있습니다.

기존 `build_household.py`, `verify_household.py`, `make_catalog.py`에 `--material-variants` 옵션을 추가해 제작·검증·카탈로그를 재사용했습니다. 신규 제작 스크립트나 게임 런타임 코드는 없습니다. 기존 공개 API, 저장 데이터, 이벤트, UI 연결과 공통 기능을 변경하거나 중복 구현하지 않았습니다.
