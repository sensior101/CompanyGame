## 폴더

| 위치 | 내용 |
| --- | --- |
| `CompanyGame/Assets/Art/Items/Food/` | 아이콘 `Food_<이름>.png` (512 × 512, 투명 배경) + Sprite용 `.meta` |
| `ArtSource/Items/Food/Models/` | 3D 모델 `Food_<이름>.obj` + `.mtl` (색마다 재질 하나, 면 법선 포함) |
| `ArtSource/Items/Food/` | 생성 코드 `generate_food.py`, `mesh3d.py`, `items_a.py`, `items_b.py`, 미리보기 `Food_Sheet.png`, `catalog.md` |

모델 크기는 대략 지름 2~3 단위이고 Y가 위입니다. Unity에 넣을 때는 Scale Factor를 상황에 맞게 조절하세요. 모델은 Assets에 넣지 않았습니다. 필요한 것만 골라 복사해서 쓰세요.

## 다시 만들기

`items_a.py`, `items_b.py`의 각 함수가 음식 하나의 모델이고, `mesh3d.py`가 도형(회전체·압출·관)과 렌더러입니다. 모양이나 색을 고치고 `python generate_food.py`를 실행하면 PNG, OBJ, 시트, 카탈로그가 다시 만들어집니다. 일부만 만들려면 `python generate_food.py Apple Bread`처럼 이름을 붙이세요(미리보기는 `preview_tmp.png`). Pillow와 numpy가 필요합니다.

새 PNG에만 `.meta`를 만들고, 이미 있는 `.meta`는 GUID 보존을 위해 건드리지 않습니다.

## Unity 가져오기 설정

`.meta`에 Sprite (2D and UI), Single, 중앙 피벗, 100 Pixels Per Unit, Alpha Is Transparency, Bilinear, Clamp, mipmap 끄기, 최대 1024를 지정했습니다(화폐 `.meta` 기준). UI에서는 Preserve Aspect를 켜세요.

## 확인한 것과 안 한 것

- 107종 모두 렌더링해서 미리보기 시트로 모양과 투명 배경을 확인했습니다. 크루아상, 밀가루·설탕·쌀·소금 포대는 다른 것보다 덜 다듬어졌습니다.
- Unity 에디터에서의 PNG 가져오기와 OBJ 가져오기는 확인하지 않았습니다.
- `ItemData` 연결, 프리팹, 아이템 획득 로직은 포함하지 않습니다.
