# 매장용 POS — 모델링 에셋

레퍼런스의 구성을 참고해 Blender에서 새로 제작한 차콜 색상 포스기입니다.
게임 코드, 상호작용 UI, 기존 씬은 수정하지 않았습니다.

## 파일

- `RetailPOS.blend`: 편집 가능한 Blender 원본. 기본 상태는 서랍 닫힘.
- `Exports/RetailPOS.fbx`: 모델과 서랍 애니메이션. 카메라·조명·렌더 바닥 제외.
- `Exports/Textures/POS_BlackScreen.png`: 기본 검정 화면 이미지.
- `Exports/RetailPOS.json`: 재질 값, 화면 오브젝트, 서랍 이동 거리와 클립 구간.
- `Preview/`: 실제 Blender 렌더. 로컬 미리보기이며 Git에서 제외.

실측 단위는 미터입니다. 현금 서랍 본체는 폭 42cm, 깊이 34cm이며,
좌우 스캐너·카드 단말기를 포함한 전체 폭은 약 67cm입니다.
형태는 23,166 삼각형, 16개 메시로 구성했습니다.

## 화면에 이미지 넣기

`Screen_Main`은 본체와 분리된 직사각형 메시입니다.
`POS_Screen_Main` 재질의 `DisplayImage` 이미지 노드를 교체하세요.
UV는 왼쪽 아래 (0,0), 오른쪽 위 (1,1)로 화면 전체를 사용합니다.
메인 화면 비율은 약 1.62:1입니다. 고객용 화면과 카드 단말기 화면도 각각
`Screen_Customer` / `Screen_Card` 및 독립 재질을 사용합니다.
고객용 화면은 점원 반대 방향을 향합니다.

Unity URP에 적용할 때 각 화면에 독립적인 URP Unlit 재질을 연결하고
Base Map에 이미지를 지정하면 됩니다. 재질을 공유하면 여러 포스기의 화면이
함께 바뀌므로 개별 표시가 필요할 때는 인스턴스 재질이나 MaterialPropertyBlock을 사용합니다.
현재 단계는 이미지 표시용 메시·UV·재질 준비까지이며, 게임의 Display 컴포넌트와
포스기 상호작용 창은 다음 구현 단계에서 연결합니다.

## 현금 서랍 열기·닫기

`CashDrawerSlide` 아래 전면 패널, 트레이, 지폐칸 4개, 동전칸 5개,
지폐 고정 클립 및 이동 레일이 함께 움직입니다. 고정 하우징은 움직이지 않습니다.

- Blender 로컬 좌표: 닫힘 Y=0, 열림 Y=-0.24m.
- Unity 내보내기 축 기준: 전방 -Z로 0.24m 이동.
- 30fps, `CashDrawer_OpenClose` 애니메이션.
- 열기: 프레임 1~31. 열린 상태 유지: 31~61. 닫기: 61~91.
- Unity Model Importer의 Animation 탭에서 위 구간을 각각
  `CashDrawer_Open`, `CashDrawer_Close`로 나누고 Loop Time을 끄세요.
- Animator 또는 해당 노드의 로컬 위치 중 하나로 제어하세요. 동시에 제어하지 마세요.

영수증 프린터·스캐너·카드 키패드는 외형만 제작했습니다.
결제, 스캔, 영수증 출력, 현금 보관 게임 기능은 포함하지 않습니다.

## 재생성 및 검증

`build_pos.py`는 새 Blender 프로세스에서 실행합니다. 현재 장면을 비웁니다.
`verify_export.py`는 FBX를 다시 불러와 화면 UV, 재질 분리, 서랍 개폐 위치,
렌더 전용 오브젝트 제외 여부를 검증합니다. 두 스크립트 모두 원본 레퍼런스를 수정하지 않습니다.
