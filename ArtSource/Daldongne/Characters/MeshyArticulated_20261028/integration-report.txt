USAGE
  Existing locomotion/seat/bicycle callers keep using their existing APIs.
  For a gesture: motion.SetFingerPose(true, 1f, true); // right index pointing
  Clear gesture: motion.SetFingerPose(true, 0f);
  For a body clip: motion.PlayClip(clip, true); motion.StopClip();
  Load the matching {Female|Male}{Walk|Run|Dance}.anim in the Animations folder.
  Body clips own the pose while playing; held-item poses do not overwrite them.
