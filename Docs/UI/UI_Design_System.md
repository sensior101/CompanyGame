# UI 디자인 시스템 (초안, 승인 전)

시안: [prototype/inventory.html](prototype/inventory.html)
- 로컬 서버로 열어야 폰트와 이미지가 보여요. 저장소 루트에서 `python -m http.server 8765`를 켜고 `/Docs/UI/prototype/inventory.html`로 들어가면 돼요.
- 캡처 이미지는 같은 폴더에 있어요.

## 1. 게임 화면 분석

| 항목 | 실제 게임 (Unity 렌더 기준) | UI에 주는 조건 |
|---|---|---|
| 모델링 | 플랫 셰이딩 저폴리, 무광, 면이 각진 실루엣. 텍스처는 벽돌 정도뿐 | 광택·그라데이션 없이 단색 면. 모서리는 둥글리기보다 **깎은 면**이 어울림 |
| 바깥 색 | 모래색 콘크리트, 올리브 잔디, 테라코타 벽돌, 슬레이트 블루 지붕, 회색 하늘. 중간 밝기, 따뜻하고 채도 낮음 | 베이지 UI가 베이지 바닥·벽에 묻힐 수 있음 → 갈색 1px 테두리 필요 |
| 실내 색 | 흰 바닥·천장, 형광등, 진열 상품만 원색 | 밝은 배경에서도 창 가장자리가 보여야 함 |
| 아이콘 | 세 가지 그림체가 섞여 있음: 실사풍 일러스트(편의점 음식에 지금 연결된 StoreFoods.jpg, 상표가 모자이크됨), 픽셀아트(ConvenienceFood/*.png), 저폴리 렌더(Items/Food/*.png) | **저폴리 렌더 하나로 통일**. 실사풍 + 모자이크가 가장 "AI 그림" 같아 보임 |

기존 UI의 문제
- 인벤토리 창이 1280 중 1100px을 덮어서 게임이 거의 안 보였어요.
- 화면마다 패널을 그리는 함수가 따로 있어서 모양과 색이 제각각이었어요.
- 글자 크기가 12~36px로 들쭉날쭉했어요.

## 2. 토큰

기준 해상도는 1280×720이에요(CanvasScaler 기준). 1080p에서는 1.5배로 커져요.

**색: 정해진 7색**

| 색 | 쓰임 |
|---|---|
| 아이보리 `#F5EEDF` | 창 바탕(92%), HUD 바탕(86%) |
| 샌드베이지 `#E9DDC8` | 장비 칸, 보조 영역 |
| 슬롯베이지 `#DCCCB4` | 아이템 칸(불투명) |
| 브라운 `#8A7258` | 테두리(50%), 구분선(26%), 빈 칸 그림. **글자에는 안 씀**(대비 3.9:1) |
| 선택 오렌지 `#E6A24C` | 선택 테두리 2px, 주 버튼 바탕 |
| 클릭 브라운오렌지 `#C97B3D` | 누른 상태, 주 버튼 아랫면 2px, 스트레스 게이지 |
| 보조 그린 `#8FAE8A` | 포만감, 좋은 효과 |

**색: 추가 4색과 이유**

| 색 | 이유 |
|---|---|
| 잉크 `#3B2F25` | 본문 글자. 브라운은 아이보리 위 대비가 3.9:1이라 작은 글자로 못 써요. 같은 색상에서 명도만 낮췄고 대비는 11.2:1이에요 |
| 잉크2 `#6E5A45` | 보조 글자. 아이보리 5.7:1, 샌드 4.9:1 |
| 레드 `#B0473B` | 체력 하트, 상함, 위험. 게임 속 벽돌색에서 가져왔어요 |
| 블루 `#5A7891` | 기력 게이지. 게임 속 지붕색에서 가져왔어요 |

**글자 (Noto Sans KR 하나, 굵기는 TMP 굵게)**

| 용도 | 크기 |
|---|---|
| 창 제목 | 18 굵게 |
| 아이템 이름 | 15 굵게 |
| 본문·버튼 | 14 |
| 값 | 13 |
| 구역 이름 | 12 굵게, 잉크2 |
| 설명 | 12, 잉크2 |
| 칸 번호 | 11 (숫자만) |

최소 크기는 12예요. 칸 번호만 예외예요.

**모양: 층마다 다른 크기의 깎은 모서리**

| 요소 | 모서리 |
|---|---|
| 창 | 6 |
| 버튼·HUD | 4 |
| 칸 | 3 |
| 게이지 칸 | 0 (네모) |
| NPC 말풍선 | 둥근 10 |

말풍선만 둥근 이유는 캐릭터의 말이고 시스템 UI가 아니라서예요. 깎은 모서리는 저폴리 면과 각진 하트 모양에서 가져왔어요.

**간격**: 4 · 8 · 12 · 16 · 24

**하지 않는 것**: 그라데이션, 광택, 그림자, 블러, 장식 테두리, 제목 옆 장식 아이콘, 색을 채운 탭

## 4. Unity 구현 방법

- **깎은 모서리**: `InventoryRoundedGraphic`에 모서리를 한 번에 깎는 옵션을 추가해요. 지금은 둥근 모서리만 그려요.
- **색**: `UITheme` 토큰을 위 값으로 교체해요. 지금 코드에는 잉크 `#5A4636`, 위험 `#C4574E`가 들어가 있어요.
- **반투명**: 색의 알파만 써요. 블러는 쓰지 않아요.
- **아이콘**: 편의점 음식의 `ItemData.icon`을 실사풍 `StoreFoods.jpg`에서 `Art/Items/Food/Food_*.png` 저폴리 아이콘으로 바꿔요.
- **인벤토리**: 폭 508, 화면 오른쪽에 붙여요. 3D 초상화(`InventoryCharacterPreview`)는 뺐어요. 3인칭에서는 캐릭터가 화면 가운데에 보이기 때문이에요. 다시 넣을지는 결정이 필요해요.

## 5. 검증 범위

**확인한 것**
- 1280×720으로 렌더한 화면을 원본 크기와 2배 확대로 직접 봤어요. 배경은 밝은 실내와 베이지 동네, 두 가지 실제 Unity 렌더예요.
- 고친 점(3회):
  - 칸 뒤로 배경 글자가 비침
  - T포즈 초상화
  - "스트레스" 줄바꿈
  - 오른쪽 끝 12px 어긋남
  - 버튼 글자가 배경에 가려짐
  - 창 바탕 86%에서 간판 글자가 비침 → 92%로 올림
- 대비는 계산으로 확인했어요.

**확인 안 한 것**
- Unity 안에서의 실제 TMP 렌더링
- 1080p 실제 모니터
- 실제 플레이 카메라 화면. 배경은 미리보기 렌더라 플레이 시점과 달라요.
- 마우스 위·드래그 같은 움직임
