# 인벤토리

## 조작과 구성

- 하단 퀵슬롯은 8칸입니다. **1~8**로 선택합니다.
- **E**로 인벤토리를 열고 **E / ESC / 닫기**로 닫습니다.
- 소지품은 기본 **8칸 × 2줄 = 16칸**입니다. 퀵슬롯은 이 중 첫 번째 줄을 표시합니다.
- 위쪽은 현재 플레이어 미리보기, **상의·하의·양말·신발** 4칸, 별도의 **펫** 영역으로 나눕니다. 선택 아이템 패널과 악세서리 장착 칸은 제거했습니다.
- 반투명 흰색 패널과 정사각형 슬롯을 사용합니다. 왼쪽 위·오른쪽 아래 모서리를 반대 대각선보다 더 둥글게 처리합니다.
- 플레이어 미리보기는 현재 캐릭터를 보여주는 전용 화면이며 마우스 회전 입력은 받지 않습니다.
- 슬롯 안에는 아이템 이름을 표시하지 않습니다. 손 커서를 올리면 작은 팝업으로 이름을 보여주며, 손 커서로 아이템을 드래그해 소지품 위치를 바꾸거나 맞는 의상·펫 칸에 장착합니다. 장착 칸에서 소지품 칸으로 옮겨 해제할 수 있습니다.
- **창 밖**으로 드래그하면 캐릭터 앞 바닥에 놓입니다. 가까이에서 **F**로 다시 줍습니다. 다른 맵을 다녀와도 같은 실행 세션 동안 남아 있습니다.
- 아이템을 클릭한 뒤 다른 소지품 칸을 클릭하면 이동·교환합니다. 같은 아이템은 최대 중첩 수까지 합칩니다.
- 선택한 아이템에 맞는 장착 칸을 클릭하면 장착합니다. 소지품을 선택하지 않고 장착 칸을 클릭하면 해제합니다. 소지품이 가득 차면 해제를 거절하고 장착 상태를 유지합니다.
- 인벤토리가 열려 있는 동안 플레이어·카메라·채팅 입력을 잠시 중지하고 닫을 때 복구합니다. 지하철·버스 선택창과 동시에 열리지 않습니다.
- 캐릭터 선택 단축키는 퀵슬롯과 겹치지 않도록 **Alt+1 / Alt+2**입니다. 마우스 휠은 기존 카메라 확대·축소에 사용합니다.

## 데이터와 연결

| 스크립트 | 역할 |
|---|---|
| `ItemData` | 공유 아이템 정의: ID, 이름, 아이콘, 종류, 중첩 한도 |
| `InventoryState` | 소지품·장착·퀵슬롯 선택·가방 확장. 실패 시 기존 아이템 보존 |
| `InventoryManager` | 맵 전환 동안 유지되는 세션 데이터 |
| `PlayerInventory` | E / ESC / 숫자 입력과 이동·카메라 제어 복구 |
| `PlayerHeldItem` | 오른손 소켓, 1인칭 팔과 아이템, 공격 시 손 움직임·사격 궤적 |
| `PlayerCombat` | 좌클릭 공격, 명중·장애물 판정, UI 중 공격 차단 |
| `PlayerStats`, `Damageable` | 공격으로 받는 피해를 체력에 반영 |
| `InventoryUI` | 하단 8칸, 소지품과 장착 창 |
| `InventoryCharacterPreview` | 실제 캐릭터의 메시·현재 자세를 별도 카메라로 표시 |
| `InventorySlotPointer`, `InventoryHandCursor` | 드래그 대상·손 커서 |
| `WorldDroppedItem` | 월드에 내려놓은 수량·액면가와 지도별 보존·줍기 |
| `BankManager` | 통장 잔액과 변경 알림 |
| `CashService` | 출금·입금, 소지 화폐 합계, 화폐 이전·결제 |
| `CurrencyIconFactory` | 사용자가 제공한 여섯 화폐 이미지 선택 |

아이템 에셋은 **Create → Company Game → Inventory → Item**에서 생성합니다. 옷·펫·가방은 1개씩, 일반 아이템은 `maxStack`을 사용합니다.

아이템 지급은 `InventoryManager.Instance.State.TryAdd(item, count, out error)`로 연결합니다. 초기 인벤토리는 비어 있습니다. 테스트용 아이템은 저장된 씬이나 실제 시작 인벤토리에 넣지 않습니다.

나중에 가방 구매 시스템에서 `TryExpandWithBag(out error)`를 호출하면 24칸으로 확장됩니다. 소지 중인 가방을 소비하는 방식은 `TryUseBag(index, out error)`를 사용합니다. 확장 후 UI는 자동으로 8칸 × 3줄이 됩니다. 추가 확장은 허용하지 않습니다. 현재 화면에는 가방 구매 안내 문구를 표시하지 않습니다.

아이템과 장착 상태는 같은 실행 세션의 지구 이동 중 유지됩니다. 게임 종료 후 저장, 상점 구매, 장착 아이템에 따른 실제 옷 메시 교체·펫 동행은 별도 연결 대상입니다.

## 통장과 소지 화폐

상시 돈 HUD는 제거하고 인벤토리 상단에 통장 잔액만 표시합니다. 금액을 클릭하면 통장 UI 바로 아래의 작은 **출금** 창에서 **금액**과 **장수**를 입력합니다. 금액 입력 후 Tab으로 장수 입력으로 이동할 수 있으며, 확인 버튼 또는 Enter로 출금합니다. 예: `1800`, `2` → 통장에서 3,600원을 차감하고 **1,800원 금동전 2개**를 지급합니다.

**금액은 동전 한 개 또는 지폐 한 장의 액면가**입니다. 총액 입력칸은 없습니다. 화폐를 선택하고 **Space**를 한 번 누르면 해당 칸의 화폐 **1개**가 사라지고 그 액면가가 통장에 입금됩니다. **Space를 누른 채 휠을 아래로** 내리면 휠 한 칸마다 1개씩 추가 입금합니다. 위로 돌릴 때는 입금하지 않습니다. 선택한 묶음이 비면 멈추고 다른 칸을 건드리지 않습니다. 이 입력 중에는 카메라 줌을 차단합니다.

인벤토리에서는 클릭한 소지품 칸, 창이 닫혀 있으면 현재 퀵슬롯을 사용합니다. 출금창·채팅·드래그·교통수단 선택 중에는 입금하지 않으며, 입금에 사용한 Space로 교통수단이 동시에 열리지 않습니다. **0원 은동전도 출금·이전·버리기·입금할 수 있습니다.** 0원 동전을 출금하거나 입금해도 통장 잔액은 변하지 않습니다. 툴팁에 실제 액면가를 표시합니다.

| 액면가 | 형태 | 이미지 |
|---|---|---|
| 0~999원 | 은동전 | CurrencySilver |
| 1,000~9,999원 | 금동전 | CurrencyGold |
| 10,000~99,999원 | 파란 지폐 | CurrencyBlue |
| 100,000~999,999원 | 초록 지폐 | CurrencyGreen |
| 1,000,000~9,999,999원 | 노란 지폐 | CurrencyYellow |
| 10,000,000원 이상 | 빨간 지폐 | CurrencyRed |

액면가는 0원 이상의 정수이며 고정 권종으로 분해하지 않습니다. 같은 액면가는 최대 99개까지 한 칸에 겹칩니다. 인벤토리 공간 부족·잔액 부족·잘못된 입력·숫자 범위 초과 시 잔액과 아이템을 모두 유지합니다.

- 출금: `CashService.TryWithdraw(inventory, faceValue, quantity, out error)`
- 입금: `CashService.TryDeposit(inventory, slot, out error)`
- 통장 조회: `CashService.BankBalance`
- 소지 화폐 합계: `CashService.CarriedTotal(inventory)`
- 화폐 자체 이전: `CashService.TryTransfer(source, recipient, slot, quantity, out error)`
- 플레이어/상인 간 결제: `CashService.TryPay(payer, recipient, amount, out error)`
- NPC 결제: `CashService.TryPayNpc(inventory, amount, out error)`

결제는 소지 화폐를 사용하며 통장에서 자동 차감하지 않습니다. 잔돈도 소지 화폐로 돌려줍니다. 0원 동전은 아이템으로 이전할 수 있지만 유료 결제 금액에는 보탬이 되지 않습니다. 거래창·네트워크 권한 검증·상점 상품 구매 연결은 별도 시스템에서 이 API를 호출해야 합니다.

## 손에 들기와 공격

- **1~8**로 선택한 퀵슬롯의 아이템을 오른손에 표시합니다. 입금·버리기·슬롯 변경·맵 이동 후에도 선택 내용과 동기화합니다.
- **Tab**으로 1인칭에 들어가면 현재 캐릭터의 오른팔과 든 아이템이 함께 보입니다. 별도 카메라가 손을 렌더링해 가까운 벽에 손이 잘리지 않도록 합니다.
- **F**는 주변 아이템 줍기입니다. 좌클릭으로 월드 아이템을 줍지 않습니다.
- **좌클릭**은 빈손일 때 주먹질, 총기를 선택했을 때 사격입니다. 무기는 `ItemCategory.Weapon`과 `WeaponKind.Firearm`으로 설정합니다. 피해량·거리·공격 간격은 `ItemData`에서 조절합니다.
- 인벤토리·채팅·교통수단 메뉴·UI 클릭 중에는 공격을 막습니다. 공격은 첫 장애물에서 멈추며, 플레이어의 `PlayerStats` 또는 대상의 `IDamageable`에 피해를 전달합니다. 일반 사물·NPC에 체력을 부여할 때 `Damageable`을 붙일 수 있습니다.
- `heldPrefab`을 지정하면 해당 메시를 손에 표시합니다. 위치·각도·크기는 `heldLocalPosition`, `heldLocalEulerAngles`, `heldLocalScale`로 맞춥니다. 지정되지 않은 화폐·아이템은 아이콘을 사용하고 총기는 기본 권총 모델을 표시합니다. 총기 지급·탄약·재장전은 별도 게임 규칙입니다.

## 검증

- `InventoryModelQA.Run()`: 빈 슬롯·중첩·교환·장착 조건·가득 찬 상태·가방 확장 32개 검사. 플레이어 데이터 대신 임시 모델 사용.
- `CashModelQA.Run()`: 금액 경계, 공간 부족, 넘침, 재진입 방지, 이전·결제 시 금액 보존 검사.
- `InventoryV2RuntimeQA.Start()`: E·Enter·F·SPACE 입력, 포인터 드래그, 슬롯 툴팁·수량 표시, 맵 왕복 후 통장·화폐·월드 아이템 보존 검사.
- `PlayerHandsRuntimeQA.Start()`: 실제 좌클릭·F·Tab·Space·휠 입력, 손 표시, 주먹·총기 명중과 벽 차단, 맵 이동 후 동기화 검사.
- 최신 결과와 화면은 `ArtSource/Inventory/QA/`에 저장합니다. 검사 중 지급하는 아이템과 금액은 Play 검사 동안만 존재합니다.
